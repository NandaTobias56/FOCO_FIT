## Como montar o quadro

1. No GitHub, aba **Projects** do perfil > **New project** > modelo **Board**.
2. Crie as etiquetas `d01` a `d15` no repositório (Issues > Labels).
3. Para cada item acima, crie uma issue com a etiqueta e adicione ao projeto.
